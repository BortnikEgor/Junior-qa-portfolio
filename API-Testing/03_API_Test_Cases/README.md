<h2>📌 About — О разделе</h2>

<p>
Данный раздел содержит тест-кейсы, подготовленные в рамках практического обучения и формирования портфолио Junior QA Engineer.
</p>

<p>
Тест-кейсы предназначены для проверки функциональности приложений и API, а также демонстрируют навыки составления тестовой документации, выполнения проверок и анализа результатов.
</p>

<hr>

<h2>📂 Test Case Categories — Категории тест-кейсов</h2>

<h3>1. Functional Testing — Функциональное тестирование</h3>

<p>
Проверка пользовательских функций и бизнес-логики приложения.
</p>

<ul>
<li>Регистрация и авторизация пользователей.</li>
<li>Валидация пользовательских данных.</li>
<li>Восстановление и изменение пароля.</li>
<li>Управление пользовательской сессией.</li>
<li>Каталог товаров и поиск.</li>
<li>Корзина и оформление заказа.</li>
<li>Проверка способов оплаты.</li>
</ul>

<h3>2. API Testing — Тестирование API</h3>

<p>
Проверка работы REST API с использованием Postman и Swagger UI.
</p>

<ul>
<li>GET — получение данных.</li>
<li>POST — создание пользователей.</li>
<li>PUT — полное обновление данных.</li>
<li>PATCH — частичное обновление данных.</li>
<li>DELETE — удаление пользователей.</li>
<li>Проверка входных данных и валидации.</li>
<li>Проверка HTTP-статусов и Response Body.</li>
<li>Проверка поиска и пагинации.</li>
</ul>

<h2>📋 Test Case Structure — Структура тест-кейса</h2>

<p>Каждый тест-кейс содержит следующие разделы:</p>

<table>
<tr>
<th>Field — Поле</th>
<th>Description — Описание</th>
</tr>
<tr>
<td>Test Case ID</td>
<td>Уникальный идентификатор тест-кейса</td>
</tr>
<tr>
<td>Title</td>
<td>Название и цель проверки</td>
</tr>
<tr>
<td>Priority</td>
<td>Приоритет выполнения</td>
</tr>
<tr>
<td>Test Type</td>
<td>Тип проверки: Positive / Negative</td>
</tr>
<tr>
<td>Preconditions</td>
<td>Условия, необходимые перед началом тестирования</td>
</tr>
<tr>
<td>Test Steps</td>
<td>Последовательность действий</td>
</tr>
<tr>
<td>Expected Result</td>
<td>Ожидаемый результат</td>
</tr>
<tr>
<td>Actual Result</td>
<td>Фактический результат</td>
</tr>
<tr>
<td>Environment</td>
<td>Окружение, в котором выполнялось тестирование</td>
</tr>
<tr>
<td>Test Execution</td>
<td>Итоговый статус выполнения проверки</td>
</tr>
</table>
