<h2>📌 ABOUT</h2>

<p>
Данный раздел содержит API-документацию тестового REST API, разработанную с использованием спецификации OpenAPI 3.0 и Swagger UI.
</p>

<p>
Документация описывает доступные API endpoints, параметры запросов, структуру request body, форматы ответов и HTTP status codes.
</p>

<p>
Цель — обеспечить возможность изучения и проверки API без необходимости обращаться непосредственно к исходному коду сервера.
</p>
