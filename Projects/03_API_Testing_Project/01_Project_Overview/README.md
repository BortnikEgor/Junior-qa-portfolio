<h2>📌 01. PROJECT DESCRIPTION — ОПИСАНИЕ ПРОЕКТА</h2>

<p>
Проект представляет собой разработку и тестирование учебного REST API для управления пользователями и товарами.
</p>

<p>
API создан на базе Node.js и Express.js и предназначен для практического изучения методов тестирования программных интерфейсов.
</p>

<p>
В рамках проекта выполняется проверка обработки HTTP-запросов, корректности бизнес-логики, валидации входных данных, структуры ответов и обработки ошибок.
</p>

<hr>

<h2>🎯 02. PROJECT OBJECTIVES — ЦЕЛИ ПРОЕКТА</h2>

<ul>
<li>Изучение принципов работы REST API.</li>
<li>Проверка доступности и корректности API-эндпоинтов.</li>
<li>Тестирование операций создания, получения, обновления и удаления данных.</li>
<li>Проверка правил валидации входных данных.</li>
<li>Проверка обработки некорректных запросов.</li>
<li>Анализ HTTP-статус-кодов и ответов сервера.</li>
<li>Проверка фильтрации и пагинации.</li>
<li>Сопоставление документации Swagger с фактическим поведением API.</li>
</ul>

<h2>🏗️ 03. API ARCHITECTURE — АРХИТЕКТУРА API</h2>

<p>Учебный API включает две основные группы ресурсов:</p>

<table>
<thead>
<tr>
<th align="left">Ресурс</th>
<th align="left">Назначение</th>
</tr>
</thead>
<tbody>
<tr>
<td><strong>Users</strong></td>
<td>Управление пользовательскими данными</td>
</tr>
<tr>
<td><strong>Products</strong></td>
<td>Управление данными о товарах</td>
</tr>
</tbody>
</table>

<h3>Users — Пользователи</h3>

<p>Предусмотрена работа со следующими полями:</p>

<ul>
<li>ID — идентификатор пользователя.</li>
<li>First Name — имя.</li>
<li>Last Name — фамилия.</li>
<li>Age — возраст.</li>
<li>City — город.</li>
<li>Country — страна.</li>
<li>Nationality — национальность.</li>
</ul>

<h3>Products — Товары</h3>

<p>Предусмотрены операции управления товарами. Конкретный состав полей определяется реализацией API.</p>
