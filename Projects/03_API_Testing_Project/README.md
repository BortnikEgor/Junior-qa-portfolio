<h2>📌 PROJECT OVERVIEW — ОБЗОР ПРОЕКТА</h2>

<p>
Данный проект представляет собой практическую работу по тестированию REST API с использованием самостоятельно разработанного учебного API.
</p>

<p>
Основная задача — проверить корректность обработки HTTP-запросов, работу CRUD-операций, валидацию входных данных, обработку ошибок и соответствие фактического поведения API документации.
</p>

<hr>

<h2>🎯 PROJECT OBJECTIVES — ЦЕЛИ ПРОЕКТА</h2>

<ul>
<li>Проверка доступности и корректности API-эндпоинтов.</li>
<li>Тестирование CRUD-операций.</li>
<li>Проверка обработки корректных и некорректных данных.</li>
<li>Проверка обязательных полей и правил валидации.</li>
<li>Проверка HTTP-методов и статус-кодов.</li>
<li>Проверка параметров запросов и фильтрации.</li>
<li>Проверка обработки ошибок.</li>
<li>Сопоставление фактических ответов API с документацией.</li>
</ul>
