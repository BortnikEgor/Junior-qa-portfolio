<p>Подготовлены 42 тест-кейса. Они ещё не все выполнены в рамках контролируемой тестовой сессии. До фактического выполнения поле Actual Result должно иметь значение <b>Not Executed — Не выполнен</b>, а статус теста не следует обозначать как Pass или Fail.</p>

Do not make a real payment solely for portfolio testing. — Проверки оплаты следует выполнять в безопасной тестовой среде либо остановить до реального списания средств.
