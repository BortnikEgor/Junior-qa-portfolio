<h2>📌 01. PROJECT OVERVIEW — ОБЩАЯ ИНФОРМАЦИЯ О ПРОЕКТЕ</h2>

<p>
This project demonstrates a structured manual testing approach applied to the public website of Managrad.
</p>

<p>
Данный проект демонстрирует структурированный подход к ручному тестированию публичного веб-сайта Managrad.
</p>

The testing scope covers the main website sections, accommodation information, booking functionality, customer-facing forms, payment-related interface elements and responsive behavior.
</p>

<p>

<h2>🎯 02. PROJECT OBJECTIVES — ЦЕЛИ ПРОЕКТА</h2>

<ul>
<li>Analyze the website structure and main user flows. — Изучить структуру сайта и основные пользовательские процессы.</li>
<li>Prepare a Test Plan and define the testing scope. — Подготовить план тестирования и определить его объём.</li>
<li>Design high-level Test Scenarios. — Разработать высокоуровневые тестовые сценарии.</li>
<li>Create detailed Test Cases with preconditions, test data, steps and expected results. — Создать подробные тест-кейсы с предусловиями, тестовыми данными, шагами и ожидаемыми результатами.</li>
<li>Identify and document reproducible defects. — Выявлять и документировать воспроизводимые дефекты.</li>
<li>Prepare a Test Summary Report based on actual execution results. — Подготовить итоговый отчёт на основании фактических результатов выполнения тестов.</li>
</ul>
