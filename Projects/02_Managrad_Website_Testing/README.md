Project Description — Описание проекта

Данный проект представляет собой практическую работу по тестированию веб-сайта Managrad.

Цель проекта — продемонстрировать навыки Junior QA Engineer в области ручного тестирования веб-приложений, анализа требований, разработки тестовой документации, проверки пользовательских сценариев и оформления Bug Reports — отчётов об ошибках.

В рамках проекта подготовлены:

⚠️ 09. TESTING LIMITATIONS — ОГРАНИЧЕНИЯ ТЕСТИРОВАНИЯ

Доступность услуг и стоимость могут изменяться.

Система бронирования может использовать сторонние сервисы.

Проверка бронирования не должна приводить к созданию реального заказа.

Реальные платежи не выполняются.

Предполагаемые дефекты необходимо подтвердить фактическими проверками.

Результаты тестирования должны фиксироваться только после выполнения соответствующих проверок.
