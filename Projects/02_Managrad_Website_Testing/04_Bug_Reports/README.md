<p>BR-001, BR-002 и BR-003 описывают текстовые ошибки, выявленные в опубликованном содержимом сайта. Скриншоты и визуальное подтверждение в браузере ещё ожидаются. Предлагаемое исправление в BR-003 следует согласовать с владельцем контента.</p>

<p>BR-004, BR-005 and BR-006 are hypothetical examples created for demonstrating Bug Reporting skills. Their described behavior has not been reproduced on the actual booking service.</p>

<p>BR-004, BR-005 и BR-006 являются гипотетическими примерами, созданными для демонстрации навыков оформления отчётов об ошибках. Описанное поведение не было воспроизведено на реальном сервисе бронирования.</p>

<h2>📋 05. BUG REPORT DOCUMENTATION — ДОКУМЕНТАЦИЯ ОТЧЁТОВ ОБ ОШИБКАХ</h2>

<p>Each Bug Report contains the following information:</p>

<ul>
<li>Bug Report Overview — Общая информация об ошибке.</li>
<li>Test Environment — Тестовое окружение.</li>
<li>Preconditions — Предварительные условия.</li>
<li>Test Data — Тестовые данные.</li>
<li>Steps to Reproduce — Шаги воспроизведения.</li>
<li>Actual Result — Фактический результат.</li>
<li>Expected Result — Ожидаемый результат.</li>
<li>Severity and Priority — Серьёзность и приоритет.</li>
<li>Reproducibility — Воспроизводимость.</li>
<li>Evidence — Доказательства.</li>
</ul>

<p>Каждый отчёт содержит описание проблемы, условия, шаги воспроизведения, фактический и ожидаемый результаты, серьёзность, приоритет и информацию о доказательствах.</p>
