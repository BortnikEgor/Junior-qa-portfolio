<h2>❌ 06. Actual Result — Фактический результат</h2>

<p>The published FAQ contains the following phrase:</p>

<p>В опубликованном FAQ присутствует следующая фраза:</p>

<blockquote>
<strong>«Дрова для растопленная печи включены в стоимость проживания»</strong>
</blockquote>

<p>The word form "растопленная" is grammatically incorrect in this sentence.</p>

<p>Форма слова «растопленная» грамматически некорректна в данном предложении.</p>

<h2>✅ 07. Expected Result — Ожидаемый результат</h2>

<p>The sentence should be corrected to:</p>

<p>Предложение должно быть исправлено на:</p>

<blockquote>
<strong>«Дрова для растопки печи включены в стоимость проживания»</strong>
</blockquote>

<p>The information should be displayed in grammatically correct Russian.</p>

<p>Информация должна отображаться на грамматически правильном русском языке.</p>
